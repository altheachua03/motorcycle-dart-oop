## Learning Objectives
To understand the basic concepts of Object-Oriented Programming in Dart, including classes, constructors, encapsulation, methods, and collections.

## Description
This Dart program demonstrates Object-Oriented Programming (OOP) concepts using motorcycle brands as real-world objects. It defines a Motorcycle class with properties such as brand, model, year, and price.

The program includes a constructor to initialize motorcycle objects, encapsulation using a private price field, methods to display motorcycle information and update the price, and a List to store multiple motorcycle objects.

## Features
- **Class and Objects:** Represents different motorcycle brands and models.
- **Constructor:** Initializes the properties of each motorcycle.
- **Encapsulation:** Uses a private `_price` field with methods to read and update its value.
- **List Usage:** Stores multiple motorcycle objects in a List.
- **Methods:** Displays motorcycle information and tests price updates.

## Technologies Used
- Dart Programming Language
- Visual Studio Code

## How to Run
1. Make sure Dart SDK is installed.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

   ```bash
   dart run motorcycle.dart
   ```
